# Lucas Santos — Portfolio

Personal portfolio site, built on top of the [vcard] template by [1chooo].

[vcard]: https://github.com/1chooo/vcard
[1chooo]: https://github.com/1chooo

## Stack

Next.js, Tailwind CSS, and TypeScript (strict mode), with static export deployed to GitHub Pages via GitHub Actions.

## Development

```bash
pnpm install
pnpm run dev
```
